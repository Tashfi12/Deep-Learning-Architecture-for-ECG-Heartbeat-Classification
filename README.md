**ECG Heartbeat Classification Using Deep Learning**

Developed and compared three deep learning architectures—1D CNN, CNN-BiLSTM, and 1D ResNet—for automated ECG heartbeat classification using a Kaggle dataset derived from the MIT-BIH Arrhythmia and PTB Diagnostic ECG databases. Evaluated model performance using accuracy, precision, recall, Macro-F1 score, and ROC-AUC, then applied hyperparameter tuning to optimize the best-performing model for cardiac rhythm classification.

**Technologies:** Python, Deep Learning, TensorFlow/Keras, 1D CNN, CNN-BiLSTM, 1D ResNet, Hyperparameter Tuning, Scikit-learn

Link of Dataset: https://www.kaggle.com/datasets/shayanfazeli/heartbeat
